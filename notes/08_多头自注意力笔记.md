# 多头自注意力（Multi-Head Self-Attention）从零读懂

> 基于 `nn_utils.py` 中的 `MultiHeadSelfAttention` 类，
> 逐行讲解这个把前面所有模块串起来的核心类。

---

## 一、整体结构

### 输入输出

```
输入: x 形状 (B, S, d_model)

            ↓

   ┌────────────────────────┐
   │  MultiHeadSelfAttention │
   │                        │
   │    Q_proj →  Q  ← RoPE │
   │    K_proj →  K  ← RoPE │
   │    V_proj →  V        │
   │                        │
   │   Attention(Q, K, V)   │
   │                        │
   │   merge heads          │
   │   O_proj               │
   └────────────────────────┘

输出: 形状 (B, S, d_model)   ← 输入输出形状相同
```

### 构造函数接收的参数

```python
def __init__(self, d_model, num_heads, use_rope=False, theta=None, max_seq_len=None):
```

| 参数 | 含义 | 典型值 |
|:----|:-----|:-------|
| `d_model` | 模型维度 | 768 |
| `num_heads` | 多头数量 | 12 |
| `use_rope` | 是否使用 RoPE | True |
| `theta` | RoPE 的基础频率 | 10000 |
| `max_seq_len` | 支持的最大序列长度 | 2048 |

`d_model` 必须能被 `num_heads` 整除。每个头的维度：

```python
self.d_k = d_model // num_heads    # 768 // 12 = 64
```

---

## 二、`__init__`：四层投影 + 可选的 RoPE

### 四个 Linear 层

```python
self.q_proj = Linear(d_model, d_model)    # Q 投影
self.k_proj = Linear(d_model, d_model)    # K 投影
self.v_proj = Linear(d_model, d_model)    # V 投影
self.o_proj = Linear(d_model, d_model)    # 输出投影
```

为什么输入输出都是 `d_model`？

- Q/K/V 投影：把输入的 d_model 维向量映射到**另一个 d_model 维空间**，方便后续拆分多头
- 输出投影：合并多头后再投影回 d_model，保持输入输出形状一致

### RoPE

```python
if use_rope:
    self.rope = RotaryPositionalEmbedding(theta, self.d_k, max_seq_len)
```

每个头独立做 RoPE，所以传入 `self.d_k`（单个头的维度），不是 `d_model`。

---

## 三、`forward` 逐行拆解

### 第 1 步：投影 Q、K、V

```python
Q = self.q_proj(x)    # (B, S, d_model)
K = self.k_proj(x)    # (B, S, d_model)
V = self.v_proj(x)    # (B, S, d_model)
```

三个独立的 Linear 层，从同一个输入 `x` 投影出 Query、Key、Value。

注意这里**三个投影的权重互不相同**，所以 Q、K、V 被投影到不同的表示空间。

### 第 2 步：拆分多头

```python
# (B, S, d_model) → (B, S, num_heads, d_k) → (B, num_heads, S, d_k)
Q = Q.reshape(*Q.shape[:-1], self.num_heads, self.d_k).transpose(-3, -2)
K = K.reshape(*K.shape[:-1], self.num_heads, self.d_k).transpose(-3, -2)
V = V.reshape(*V.shape[:-1], self.num_heads, self.d_k).transpose(-3, -2)
```

这是关键的一步。分两步看：

**① reshape**

```python
# 形状变化: (B, S, 768) → (B, S, 12, 64)
Q = Q.reshape(*Q.shape[:-1], self.num_heads, self.d_k)
```

把最后一维 `d_model=768` 分成 `(12, 64)`——12 个头，每个头 64 维。

**② transpose**

```python
# 形状变化: (B, S, 12, 64) → (B, 12, S, 64)
Q = Q.transpose(-3, -2)
```

把 `num_heads` 维和 `seq_len` 维交换。为什么？

```
reshape 后: (B, S, 12, 64)     ← 每个位置存 12 个头
transpose 后: (B, 12, S, 64)   ← 每个头存一个完整的 S×64 序列
```

Attention 需要对每个头**独立算**，所以要把头维度搬到前面，让 `S×d_k` 成为最后两维。

这个形状 `(B, num_heads, S, d_k)` 可以理解成：**B×num_heads 个独立的注意力计算**，每个处理 S 个 token、d_k 维向量。

```
         batch  head   seq   dim
Q 形状:  (B,    H,     S,    d_k)
K 形状:  (B,    H,     S,    d_k)
V 形状:  (B,    H,     S,    d_k)
```

### 第 3 步：应用 RoPE（可选）

```python
if self.use_rope:
    Q = self.rope(Q, token_positions)    # (B, H, S, d_k)
    K = self.rope(K, token_positions)    # (B, H, S, d_k)
```

对每个头的 Q 和 K 都施加旋转位置编码。V 不参与，因为 V 只做加权求和。

`token_positions` 是每个 token 在原始序列中的位置索引。

### 第 4 步：构建因果 mask

```python
mask = torch.tril(torch.ones((S, S), device=x.device, dtype=torch.bool))
```

`torch.tril` 取**下三角**：

```
S=4:
tensor([
    [True,  False, False, False],    ← 第 0 个 token 只能看自己
    [True,  True,  False, False],    ← 第 1 个 token 能看 0, 1
    [True,  True,  True,  False],    ← 第 2 个 token 能看 0, 1, 2
    [True,  True,  True,  True ],    ← 第 3 个 token 能看全部
])
```

这就是因果掩码（causal mask）——保证自回归生成时不会看到未来的 token。

### 第 5 步：调用 Attention

```python
attn_output = scaled_dot_product_attention(Q, K, V, mask)
```

传入我们之前实现的 `scaled_dot_product_attention`：

```
Q: (B, H, S, d_k)     K: (B, H, S, d_k)     V: (B, H, S, d_k)
                            ↓
                   Attention(Q, K, V, mask)
                            ↓
attn_output: (B, H, S, d_k)     ← 每个头输出 S×d_k
```

内部经历了：

```
Q @ K^T → (B, H, S, S)     ← 每个头算自己的注意力分数
   ↓ masked_fill            ← 因果掩码，未来位置设为 -inf
   ↓ softmax(dim=-1)        ← 沿 S 维归一化成概率
   ↓ @ V                    ← 加权聚合
输出: (B, H, S, d_k)
```

### 第 6 步：合并多头

```python
# (B, H, S, d_k) → (B, S, H, d_k) → (B, S, d_model)
res = attn_output.transpose(-3, -2).reshape(
    *attn_output.shape[:-3], x.shape[-2], self.d_model
)
```

和拆分是反向操作：

```python
transpose(-3, -2)     # (B, H, S, d_k) → (B, S, H, d_k)
reshape(...)           # (B, S, H, d_k) → (B, S, H×d_k) = (B, S, d_model)
```

合并后的张量恢复成 `(B, S, d_model)`，每个位置有完整的信息，融合了所有头的输出。

### 第 7 步：输出投影

```python
res = self.o_proj(res)    # (B, S, d_model) → (B, S, d_model)
```

最后用一个 Linear 层做输出投影，让模型能**整合所有头的信息**并映射回输出空间。

## 四、完整流程图示

```
输入 x (B, S, d_model)
    │
    ├── q_proj ──→ Q (B, S, d_model)
    │                │ reshape + transpose
    │                ↓ Q (B, num_heads, S, d_k)
    │                │ (RoPE)
    │                ↓ Q_rot (B, num_heads, S, d_k)
    │
    ├── k_proj ──→ K (B, S, d_model)
    │                │ reshape + transpose
    │                ↓ K (B, num_heads, S, d_k)
    │                │ (RoPE)
    │                ↓ K_rot (B, num_heads, S, d_k)
    │
    ├── v_proj ──→ V (B, S, d_model)
    │                │ reshape + transpose
    │                ↓ V (B, num_heads, S, d_k)
    │
    │   Q_rot, K_rot, V → Attention(Q, K, V, mask)
    │                           ↓
    │                    attn_out (B, num_heads, S, d_k)
    │                           │ transpose + reshape
    │                           ↓
    │                    out (B, S, d_model)
    │                           │ o_proj
    │                           ↓
    └──────────────────→ res (B, S, d_model)
```

## 五、为什么用多头？

### 核心思路

$$
d_{	ext{model}} = 	ext{num\_heads} 	imes d_k
$$

把 $d_{	ext{model}}$ 维空间切分成 $	ext{num\_heads}$ 个 $d_k$ 维子空间，在每个子空间里**独立并行做 Attention**，最后把所有结果拼回 $d_{	ext{model}}$ 维。

```
单头:  1 次 Attention，只能学到一种注意力模式

多头:  H 次独立的 Attention，H 个子空间的结构不同
       → 每个头学到不同的 Q/K/V 投影权重
       → 算出的注意力权重矩阵不同
       → 有的关注相邻词、有的关注句首、有的关注长程依赖
       → 拼起来得到的信息比单头更丰富
```

### 关键性质

| 角度 | 说明 |
|:----|:-----|
| 参数量不变 | 每个头维度 $d_k = d_{	ext{model}} / H$，总参数量和单头一致 |
| 并行计算 | H 个头在同一个张量运算中完成，不增加顺序计算量 |
| 自主分工 | 不指定每个头学什么，训练中通过 BP 自行分化 |
| 信息更丰富 | 从 H 种不同角度加权汇总，拼成最终输出 |

> 本质上就是：**把 $d_{	ext{model}}$ 分组为若干子空间，并行跑注意力机制，拼起来后发现的信息比单头更多。**

## 六、和前续各层的关系

这个 `MultiHeadSelfAttention` 是前面所有模块的**组装者**：

| 前续模块 | 在这个类里的作用 |
|:---------|:---------------|
| **Linear** | Q/K/V/O 四个投影层都由 Linear 实现 |
| **RoPE** | 可选的旋转位置编码 |
| **scaled_dot_product_attention** | 核心的注意力计算 |
| **softmax** | Attention 内部用到（被 sdp_attention 调用） |

它自己不做新的数学变换——只是把前面各层按正确的顺序装配起来。
