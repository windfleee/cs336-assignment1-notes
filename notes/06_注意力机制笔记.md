## 一、点积注意力在干什么——查字典的高级版

### 公式

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

| 符号 | 名字 | 类比 |
|:----|:-----|:-----|
| $Q$ (Query) | 查询向量 | 你在搜索引擎里输入的"问题" |
| $K$ (Key) | 关键字向量 | 数据库中每个文档的"标题" |
| $V$ (Value) | 价值向量 | 数据库中每个文档的"正文内容" |

### 直观理解

整个过程分三步：

```
Q (查询)                        K (关键字)               V (价值)
  │                               │                      │
  │  和每个 K 做点积               │                      │
  ├─────→  [0.8, 0.1, 0.3]  ←────┘                      │
  │         ↑ 点积结果越大→越相似                          │
  │                                                      │
  │  softmax → [0.6, 0.1, 0.3]  ← 变成概率，和为 1       │
  │                                                      │
  │  用概率对 V 加权                                      │
  └───────────────────────────────────→  [V₀×0.6 + V₁×0.1 + V₂×0.3]
                                          ↑ 和 Q 最相似的那个 K 对应的 V 占大头
```

### 用 RAG 类比

你在图书馆查资料：

```
你脑子里想的："Transformer 的注意力机制怎么工作？"
        │
        ▼
  这就是 Q（查询向量）

你把这个念头和每本书的"目录"（K）做对比：
  ├─ "深度学习入门"    → 目录匹配度 0.9
  ├─ "Python 语法"     → 目录匹配度 0.1
  └─ "自然语言处理"    → 目录匹配度 0.6

然后你翻到对应的"正文内容"（V）：
  输出 = 深度学习书 × 0.9 + Python书 × 0.1 + NLP书 × 0.6
```

**相似度越高的 Key，其 Value 在最终结果中占的比重越大。**

## 二、代码逐行讲解

### 完整代码

```python
def scaled_dot_product_attention(Q, K, V, mask=None):
    qkt = torch.matmul(Q, K.transpose(-2, -1)) / (Q.shape[-1] ** 0.5)

    if mask is not None:
        qkt = qkt.masked_fill(mask == False, float('-inf'))

    scaled_attention = softmax(qkt, dim=-1)

    return scaled_attention @ V
```

### 第 1 行：计算注意力分数

```python
qkt = torch.matmul(Q, K.transpose(-2, -1)) / (Q.shape[-1] ** 0.5)
```

这一行做了整个公式最核心的两部分。

**① Q @ Kᵀ**

```
Q 形状: (..., queries, d_k)          ← 每个 query 是一个 d_k 维向量
K 形状: (..., keys, d_k)             ← 每个 key 是一个 d_k 维向量

K.transpose(-2, -1) 形状: (..., d_k, keys)

Q @ Kᵀ 形状: (..., queries, keys)    ← 每个 query 和每个 key 的点积
```

点积的结果是一个分数矩阵：

```
               K₀     K₁     K₂
          ┌─────────────────────┐
    Q₀    │  0.9   0.1   0.6   │
    Q₁    │  0.2   0.8   0.3   │
    Q₂    │  0.4   0.4   0.9   │
          └─────────────────────┘
  qkt[i][j] = Qᵢ · Kⱼ = Qᵢ 和 Kⱼ 的相似度
```

**为什么是 `.transpose(-2, -1)` 不是 `.T`？**

`.T` 只能处理 2D 矩阵。`.transpose(-2, -1)` 对任意维度的张量都有效——只交换最后两维，前面的 batch 维不动。

```
Q 形状 [B, H, S, d_k]         ← 多头注意力的实际形状
K.transpose(-2, -1) 形状 [B, H, d_k, S]
matmul 结果 [B, H, S, S]      ← 每个头各自算注意力
```

**② 除以 √dₖ**

```python
/ (Q.shape[-1] ** 0.5)
```

`Q.shape[-1]` 就是 $d_k$，`** 0.5` 就是开平方。

**为什么除？** 见下面第四节。

### 第 2~3 行：应用 mask

```python
if mask is not None:
    qkt = qkt.masked_fill(mask == False, float('-inf'))
```

mask 是一个布尔张量，形状 `(..., queries, keys)`：

- `True` → 保留这个位置，允许 attend
- `False` → 把这个位置的分数设成 $-\infty$，softmax 后变成 0

```
mask 例子（因果掩码）:

     K₀  K₁  K₂
Q₀  [1,  0,  0]     ← Q₀ 只能看到 K₀
Q₁  [1,  1,  0]     ← Q₁ 只能看到 K₀, K₁
Q₂  [1,  1,  1]     ← Q₂ 能看到全部
```

为什么用 $-\infty$ 不是 0？因为设有 0，softmax 后还会分到一点概率。设成 $-\infty$ 后 softmax 输出 0，完全不看。

### 第 4 行：softmax 归一化

```python
scaled_attention = softmax(qkt, dim=-1)
```

沿 `keys` 维（最后一维）做 softmax，让每个 query 对所有 key 的注意力权重加起来为 1。

```
softmax 前: qkt = [[0.9, 0.1, 0.6], ...]    ← 任意实数
                      ↓
softmax 后: attn = [[0.5, 0.2, 0.3], ...]    ← 和为 1 的概率
```

### 第 5 行：加权聚合

```python
return scaled_attention @ V
```

```
attn 形状: (..., queries, keys)     ← 注意力权重（概率）
V 形状:    (..., keys, d_v)         ← 价值向量的序列

输出形状: (..., queries, d_v)       ← 每个 query 拿到一个 d_v 维向量
```

每个 query 的输出是所有 value 向量的**加权平均**——权重就是 attn 里的概率。

```python
output[i] = attn[i][0] × V[0] + attn[i][1] × V[1] + attn[i][2] × V[2]
```

## 三、完整例子

```python
d_k = 4
d_v = 3

# 2 个 query, 3 个 key/value
Q = torch.tensor([
    [1.0, 0.0, 1.0, 0.0],           # Q₀
    [0.0, 1.0, 0.0, 1.0],           # Q₁
])
K = torch.tensor([
    [0.8, 0.2, 0.9, 0.1],           # K₀
    [0.1, 0.9, 0.2, 0.8],           # K₁
    [0.5, 0.5, 0.5, 0.5],           # K₂
])
V = torch.tensor([
    [1.0, 0.0, 0.0],                 # V₀
    [0.0, 1.0, 0.0],                 # V₁
    [0.0, 0.0, 1.0],                 # V₂
])
```

逐步骤看：

```
① Q @ Kᵀ / √4:
   Q₀·K₀ = 1×0.8 + 0×0.2 + 1×0.9 + 0×0.1 = 1.7  → /2 = 0.85
   Q₀·K₁ = 1×0.1 + 0×0.9 + 1×0.2 + 0×0.8 = 0.3  → /2 = 0.15
   Q₀·K₂ = 1×0.5 + 0×0.5 + 1×0.5 + 0×0.5 = 1.0  → /2 = 0.50

② softmax:
   Q₀ 的注意力: [0.47, 0.23, 0.30]    ← Q₀ 和 K₀ 最相似
   Q₁ 的注意力: [0.23, 0.47, 0.30]    ← Q₁ 和 K₁ 最相似

③ @ V:
   output[Q₀] = 0.47×[1,0,0] + 0.23×[0,1,0] + 0.30×[0,0,1]
            = [0.47, 0.23, 0.30]
   output[Q₁] = 0.23×[1,0,0] + 0.47×[0,1,0] + 0.30×[0,0,1]
            = [0.23, 0.47, 0.30]
```

每个 query 的输出更接近和自己最相似的 key 对应的那个 value。

## 四、为什么除以 √dₖ？

### 方差为什么会是 $d_k$？

要解释清楚，得从单个乘积项一步步算。

假设 $Q$ 和 $K$ 的每个分量都是独立同分布，均值 0、方差 1。

单个乘积项 $q_i \cdot k_i$ 的方差：

$$
\begin{aligned}
\text{Var}(q_i \cdot k_i)
&= E[(q_i \cdot k_i)^2] - E[q_i \cdot k_i]^2 \\
&\quad\text{(因为 } q_i,\,k_i \text{ 独立，展开括号)} \\
&= E[q_i^2]\cdot E[k_i^2] - E[q_i]^2\cdot E[k_i]^2 \\
&\quad\text{(代入 } E[q_i^2]=1,\,E[k_i^2]=1,\,E[q_i]=0,\,E[k_i]=0\text{)} \\
&= 1 \cdot 1 - 0 \cdot 0 \\
&= 1
\end{aligned}
$$



$$
\underbrace{\text{Var}(\underbrace{Q_i \cdot K_j}_{\text{一个点积，即 }(Q @ K^T)[i][j]})}_{\text{矩阵 }Q @ K^T \text{中一个元素的方差}} = \sum_{t=1}^{d_k} \text{Var}(q_t \cdot k_t) = d_k \times 1 = d_k
$$

也就是说点积的方差和维度 $d_k$ 成正比。

> **为什么只看一个元素？** $Q @ K^T$ 的结果是一个形状为 $(queries, keys)$ 的矩阵，
> 里面有 $queries \times keys$ 个元素，每个元素都是一个点积标量。
> 这些标量**各自独立地**喂进 softmax，所以我们只关心**单个点积的方差**——
> 它是 $d_k$ 个独立乘积项的和，所以 $\text{Var}(\text{score}) = d_k$。
> 这个方差和 $queries$、$keys$ 的数量无关，只取决于 $d_k$（向量的长度）。

### 对 softmax 的影响

当 $d_k = 768$（LLaMA 的维度）：

```
点积的方差 ≈ 768，标准差 ≈ 27.7
分数分布在 [-80, 80] 这个范围
```

这么大的数进了 softmax，最大的那个几乎垄断全部概率：

```
输入: [80, 75, 70]
e⁸⁰ / (e⁸⁰ + e⁷⁵ + e⁷⁰) ≈ 0.99     ← 几乎全是第一个
```

这就是 **softmax 进入饱和区**——输出几乎变成 one-hot，梯度接近 0，模型学不动。

### 除以 $\sqrt{d_k}$ 把方差拉回来

现在除以 $\sqrt{d_k}$ 缩放：

$$
\text{Var}\left(\frac{Q \cdot K}{\sqrt{d_k}}\right)
= \frac{1}{d_k} \cdot \text{Var}(Q \cdot K)
= \frac{d_k}{d_k} = 1
$$

方差恢复成 1，softmax 的输入回到温和的区域：

```
除以 √768 ≈ 27.7 后：
输入: [2.89, 2.71, 2.53]           ← 方差≈1
softmax: [0.42, 0.32, 0.26]        ← 分布更均匀
```

越大 $d_k$，除以 $\sqrt{d_k}$ 的效果越明显。这就是"scaled"（缩放）的含义——**把点积分数的尺度拉回 softmax 的舒适区**。

## 五、mask 的两种常见用法

### 1. 因果掩码（Causal Mask）——Decoder 自注意力

防止模型看到"未来的 token"：

```
              K₀         K₁         K₂       ← keys
           "the"      "cat"      "sat"
Q₀ "the"    ✅(0)    ❌(-inf)   ❌(-inf)   ← Q₀ 只能看 K₀
Q₁ "cat"    ✅(0)    ✅(0)     ❌(-inf)   ← Q₁ 能看 K₀, K₁
Q₂ "sat"    ✅(0)    ✅(0)     ✅(0)     ← Q₂ 能看全部
↑
queries

下三角矩阵：右上角 ❌(-inf) → 看不到未来的 token
```

### 2. Padding 掩码

把填充位置的 token 遮掉：

```
句子: ["hello", "world", <pad>, <pad>]
mask: [True,   True,   False,  False]
```

## 六、和之前各层的关系——完整流水线

现在已经讲完了 Transformer 里最核心的几个构件，整个流程串起来：

```
文本 "hello world"
    │
    ▼ Tokenizer            笔记 01: 文本 → token ID
[1523, 42, ...]
    │
    ▼ Embedding            笔记 03: ID → 向量
 [v₀, v₁, ...]             形状 [B, S, d_model]
    │
    ▼ RMSNorm              笔记 04: 归一化稳定分布
 [v₀', v₁', ...]           形状不变
    │
    ▼ Linear → Q, K, V     笔记 02: 加权变换
 [Q, K, V]                 从同一个输入用三个不同的 Linear 投影出来
    │
    ▼ Softmax + Attention  笔记 05 + 当前笔记
    注意力加权汇总          输出形状 [B, S, d_v]
```

## 七、和之前各层的对比

| 层/函数 | 做的事 | 有无可学习参数 | 有无可学习参数 |
|:--------|:-------|:-------------|:-------------|
| **Linear** | 矩阵乘法加权 | ✅ | `weight` |
| **Embedding** | 查表映射 | ✅ | `weight` |
| **RMSNorm** | 归一化 | ✅ | `weight`（缩放系数） |
| **Softmax** | 分数→概率 | ❌ | 纯函数 |
| **Attention** | 按相关性加权汇总 | ❌ | 纯函数（QKV 来自前面的 Linear） |

Attention 本身没有参数——它的参数来自于生成 Q、K、V 的那三个 Linear 层。
