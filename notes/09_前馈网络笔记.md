## 一、为什么 Transformer 需要 FFN？

Attention 做的事情是：**每个 token 从序列中的其他 token 那里收集信息**。

但光收集不够——模型还需要一个**非线性变换**来对收集到的信息做进一步处理：

```
Attention 输出:  每个 token 的向量包含了上下文信息
       ↓
FFN:            对每个 token 独立做非线性变换，增强表达能力
       ↓
输出:            维度不变，但内容经过了更复杂的映射
```

简单说：
- **Attention** 是在 token 之间交换信息（横向）
- **FFN** 是在每个 token 内部做深层变换（纵向）

## 二、激活函数优劣对比

激活函数是神经网络的"非线性来源"——没有它，多层 Linear 堆叠等价于一层 Linear。

### Sigmoid

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$
```

| 优点 | 缺点 |
|:----|:-----|
| 输出在 $(0,1)$，天然适合做概率 | **两端梯度饱和**：$x \to \pm\infty$ 时梯度 $\to 0$，梯度消失 |
| 平滑可导 | 输出不以 0 为中心，影响收敛速度 |

```
sigmoid
 1.0 ┤       ╭━━━━━━━━━━━╮
     │      ╱               ╲
 0.5 ┤─────╯                 ╰─────
     │                          ← 两端几乎平了，梯度≈0
 0.0 ┼─────────────────────────
    -5         0          5
```

### Tanh

$$
\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
$$

| 优点 | 缺点 |
|:----|:-----|
| 输出在 $(-1,1)$，以 0 为中心 | **两端同样饱和**，梯度消失问题没解决 |
| 比 sigmoid 收敛快 | 计算比 sigmoid 复杂一点点 |

```
tanh
 1.0 ┤        ╭━━━━━━╮
     │      ╱          ╲
 0.0 ──────╯            ╰──────
     │                     ← 两端也是平的
-1.0 ┤
    -5         0          5
```

### ReLU

$$
\text{ReLU}(x) = \max(0, x)
$$

| 优点 | 缺点 |
|:----|:-----|
| **计算极快**：就一个 max | **负半轴死了**：$x<0$ 时梯度恒为 0，神经元可能永久死亡 |
| 正半轴梯度恒为 1，不饱和 | 输出不以 0 为中心 |
| 大大缓解梯度消失 | |

```
ReLU
 5.0 ┤                        ╱
     │                      ╱
     │                    ╱
 0.0 ───────────────────╯
     │  ← 死了          ← 活的
    -5         0          5
```

### Swish / SiLU

$$
\text{SiLU}(x) = x \cdot \sigma(x)
$$

| 优点 | 缺点 |
|:----|:-----|
| **处处可导、不饱和**：负半轴有微小负梯度，不会死 | 计算比 ReLU 稍慢（需要算 sigmoid） |
| 负半轴有信息保留：小的负值能继续传播 | |
| 自门控：自动调节信息通过量 | |

```
SiLU
 5.0 ┤                        ╱
     │                      ╱
     │                    ╱
 0.0 ───────╮            ╱
     │        ╲        ╱       ← 负半轴还有一点梯度
     │          ╲    ╱
     │            ╲╱
    -5         0          5
```

### 对比总表

| 函数 | 公式 | 梯度饱和 | 负半轴 | 计算量 | 主流用途 |
|:----|:-----|:--------|:------|:------|:--------|
| **Sigmoid** | $1/(1+e^{-x})$ | ❌ 两端饱和 | 接近 0 | 中等 | 输出层概率 |
| **Tanh** | $(e^x-e^{-x})/(e^x+e^{-x})$ | ❌ 两端饱和 | 接近 -1 | 中等 | RNN |
| **ReLU** | $\max(0,x)$ | ✅ 正半轴不饱和 | 恒为 0（神经元会死） | **极低** | CNN、早期 Transformer |
| **SiLU** | $x \cdot \sigma(x)$ | ✅ 不饱和 | 小负值保留 | 稍高 | **LLaMA、现代 LLM** |

为什么大模型现在都用 SiLU 而不是 ReLU？因为 ReLU 的负半轴死透了，而大模型的深层网络中，激活函数承担着更复杂的"门控"功能——需要负半轴保留一点信息，而不是一刀切。

## 三、SiLU 代码逐行

### 完整代码

```python
def silu(in\_features):
    return in\_features * torch.sigmoid(in\_features)
```

**一行代码，一件事：$x \cdot \sigma(x)$**

```python
# 假设输入是 3 个值
x = torch.tensor([-3.0, 0.0, 3.0])

sigmoid(x) = [0.047, 0.5, 0.953]       ← 0~1 之间
x * sigmoid(x) = [-0.142, 0.0, 2.858]   ← 负半轴保留了 -0.142，不是 0
```

SiLU 的形状：**负半轴经过 sigmoid 压缩后接近 0 但不等于 0，梯度能继续向后传。**

## 四、SwiGLU 代码逐行

### SwiGLU 是什么

SwiGLU 不是单纯的激活函数，它是**一个完整的 FFN 模块**，LLaMA 系列用的就是它。

公式：

$$
\text{SwiGLU}(x) = (\text{SiLU}(x \cdot W\\\_1^T) \odot (x \cdot W\\\_3^T)) \cdot W\\\_2^T
$$

其中 $\odot$ 是逐元素乘法。

### 完整代码

```python
class SwiGLU(nn.Module):
    def \\_\\_init\\_\\_(self, d\\_model, d\\_ff, device=None, dtype=None):
        super().\\_\\_init\\_\\_()
        self.d\\_ff = d\\_ff
        self.d\\_model = d\\_model
        self.w1 = Linear(d\\_model, d\\_ff)    # gate 通路
        self.w2 = Linear(d\\_ff, d\\_model)    # 输出投影
        self.w3 = Linear(d\\_model, d\\_ff)    # up 通路

    def forward(self, x):
        return self.w2(
            silu(self.w1(x)) * self.w3(x)
        )
```

有三个 Linear 层，比传统 FFN 多一个。

### 传统 FFN（ReLU 版本）

```
FFN(x) = W₂ · ReLU(W₁ · x)     ← 两个 Linear + 一个 ReLU
```

### SwiGLU 的结构

```
          ┌── x ──→ W₁ ──→ SiLU ──┐
          │                        │
          └── x ──→ W₃ ───────────┼──→ × ──→ W₂ ──→ 输出
                                  │
```

拆解代码：

```python
def forward(self, x):
    # Step 1: gate = SiLU(x @ W1^T)
    gate = silu(self.w1(x))   # (B, S, d\\_model) → (B, S, d\\_ff)

    # Step 2: up = x @ W3^T
    up = self.w3(x)            # (B, S, d\\_model) → (B, S, d\\_ff)

    # Step 3: gate * up 逐元素乘（信息筛选）
    gated = gate * up          # (B, S, d\\_ff) ← 形状不变

    # Step 4: 输出投影
    return self.w2(gated)      # (B, S, d\\_ff) → (B, S, d\\_model)
```

### 第三步是核心：门控机制

```python
gated = gate * up    # 逐元素乘
```

`gate`（经过 SiLU）决定"让多少信息通过"，`up` 提供信息内容。

```
类比：gate 是阀门，up 是水流
gate 值大（接近 1）→ 水流通畅
gate 值小（接近 0）→ 水流被截住
gate 为负 → 信息反向
```

```
gate 中某位置的值:   0.95  0.02   -0.30   0.80     ← 阀门开度
up   中对应位置的值:  4.20  3.10   -2.50   1.50     ← 原始信息
                ×
结果:                3.99  0.06    0.75   1.20     ← 筛选后的信息
```

相比 ReLU 的"硬的死"（负半轴直接归零），SwiGLU 的 SiLU 门控更"软"——负半轴的小值可以反向调节信息，给模型更强的表达能力。

### 形状变化一览

```
输入 x:           (B, S, d\\_model)
    │
w1(x): SiLU 门控  → (B, S, d\\_ff)
w3(x): up 通路     → (B, S, d\\_ff)
    │
gate * up          → (B, S, d\\_ff)    ← 逐元素乘
    │
w2(gated)          → (B, S, d\\_model) ← 投影回 d\\_model
```

$d\\\_{ff}$ 通常比 $d\\\_{\text{model}}$ 大很多（LLaMA: $d\\\_{\text{model}}=4096$, $d\\\_{ff}=11008$），所以 FFN 先**扩大再压缩**，给模型更多参数空间去变换信息。

## 五、FFN 在 Transformer 中的位置

```
输入 x (B, S, d\\_model)
    │
    ├── RMSNorm(x)
    ├── MultiHeadSelfAttention(x)
    ├── + 残差连接
    │
    ├── RMSNorm(x)
    ├── SwiGLU(x)                ← FFN 在这里
    ├── + 残差连接
    │
    输出 (B, S, d\\_model)
```

每一层 Transformer 由一个 Attention 子层 + 一个 FFN 子层组成。FFN 对每个 token 独立处理，不跨 token 交换信息。
